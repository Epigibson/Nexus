---

```bash
nexus profiles [project-name]
```

## Descripción

El comando `nexus profiles` cumple dos funciones:

1. **Sin argumentos**: Muestra el estado de instalación actual de todas las herramientas CLI compatibles globales de la máquina y sus perfiles de autenticación activos en el sistema (por ejemplo, qué cuenta de GitHub o AWS está activa actualmente en tu terminal).
2. **Con argumento (`project-name`)**: Busca el proyecto especificado (en los archivos YAML locales, la carpeta `~/.nexus/projects/`, o en el caché de la nube si está autenticado) y muestra qué perfiles de CLI (`gh`, `aws`, `supabase`, etc.) están asignados para cada uno de sus entornos.

## Parámetros

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| `project-name` | string | No | Nombre o slug del proyecto a inspeccionar |

nexus profiles
