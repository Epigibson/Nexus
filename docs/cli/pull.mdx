```bash
nexus pull <project-slug>
```

## Descripción

El comando `nexus pull` descarga la estructura de configuración completa de un proyecto desde la plataforma en la nube de Nexus y la escribe en un archivo local `nexus.yaml` en tu directorio actual.

Es de gran utilidad para:
1. Descargar la configuración de un proyecto creado en el Dashboard en una carpeta local limpia de desarrollo.
2. Versionar el archivo de configuración `nexus.yaml` en tu repositorio Git.

<Info>
  Requiere autenticación activa a través de `nexus login`.
</Info>

## Parámetros

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| `project-slug` | string | ✅ | El slug identificador único del proyecto en la nube |

## Ejemplo de salida

```bash
nexus pull michicondrias
```

```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Successfully downloaded configuration to nexus.yaml
```
